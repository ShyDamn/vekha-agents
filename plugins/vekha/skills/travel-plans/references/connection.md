Codex Windows: the downloadable package contains Install-Vekha.vbs and Connect-Vekha.vbs. The connection form has a password field, verifies the key, and stores it with Windows CurrentUser encryption. Help open that form when authorized; never ask the human to paste a key into chat, source, URLs or ordinary files. Existing stored credentials survive plugin updates. Open a new chat after connection; restart Codex only if tools remain absent. Claude Desktop MCPB uses its sensitive extension setting.

A pasted key does not configure MCP. Distinguish missing installation, missing connection, expired/revoked access and missing scopes. Do not pretend to read data without tools. The human can upgrade an existing key to trip-document mode in Vekha without changing its secret; explain that already connected assistants then inherit current and future nonpersonal documents visible to that key owner. Never silently change permissions or bypass them using account credentials.
